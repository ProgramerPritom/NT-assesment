# 🗺️ NexusWMS — Implementation Plans Directory

এই ডিরেক্টরিতে প্রজেক্টের প্রতিটি অংশের জন্য আলাদা আলাদা সুনির্দিষ্ট ও বিস্তারিত প্ল্যানিং ফাইল রয়েছে। প্রতিটি ফাইলে **Phase by Phase** কাজের তালিকা, প্রয়োজনীয় কম্পোনেন্টস, লজিক, রুলস এবং **DOD (Definition of Done)** সুস্পষ্টভাবে উল্লেখ করা হয়েছে।

---

### 📂 প্ল্যানিং ফাইলসমূহের তালিকা:

1. **[FRONTEND_PLAN.md](./FRONTEND_PLAN.md)**
   * ফ্রন্টএন্ডের সমস্ত পেজ, লেআউট, মডাল, ড্রয়ার এবং UI স্টেটসের ফেজ-ভিত্তিক পরিকল্পনা (মোট ১০টি সুনির্দিষ্ট ফেজ)।
   * হিউম্যান-ডিজাইন নির্দেশিকা (যাতে কোনোভাবেই এআই-জেনারেটেড না দেখায়)।
   * প্রতিটি পেজের জন্য আলাদা DOD চেকলিস্ট।

2. **[BACKEND_PLAN.md](./BACKEND_PLAN.md)**
   * ব্যাকএন্ড REST API এন্ডপয়েন্টস, মিডলওয়্যার, রিকোয়েস্ট ভ্যালিডেশন এবং বিজনেস কন্ট্রোলারের ফেজ-ভিত্তিক পরিকল্পনা।
   * প্রতিটি এপিআই-এর মেথড, রিকোয়েস্ট বডি, রেসপন্স ও রোল পারমিশন।
   * প্রতিটি ফেজের DOD চেকলিস্ট।

3. **[DATABASE_PLAN.md](./DATABASE_PLAN.md)**
   * Prisma ORM কনফিগারেশন (লোকাল SQLite ও প্রোডাকশন PostgreSQL)।
   * ৭টি রিলেশনাল টেবিল ডিজাইন ও ট্রানজেকশনাল ইন্টিগ্রিটি।
   * রিয়েলিস্টিক সিড ডাটা (Demo Users, Suppliers, Products)।
   * ডাটাবেজ ফেজের DOD চেকলিস্ট।

4. **[AI_ENGINE_PLAN.md](./AI_ENGINE_PLAN.md)**
   * Google Gemini 1.5 Flash এপিআই ইন্টিগ্রেশন ও স্ট্রাকচার্ড JSON প্রম্পট ডিজাইন।
   * গাণিতিক ব্লাস্ট রেডিয়াস রিস্ক স্কোরিং অ্যালগরিদম।
   * হিউম্যান-ইন-দ্য-লুপ (HITL) এপ্রুভাল পাইপলাইন ও অফলাইন ফলব্যাক।
   * এআই ফেজের DOD চেকলিস্ট।

### 🔑 প্রয়োজনীয় ক্রেডেনশিয়াল চেকলিস্ট (Credentials Requirements):

| সার্ভিস | কোন ফেজে লাগবে? | এনভায়রনমেন্ট ভ্যারিয়েবল | কীভাবে সংগ্রহ করবেন? |
| :--- | :--- | :--- | :--- |
| **JWT Secret** | Backend Phase 1 (Auth) | `JWT_SECRET` | যেকোনো নিরাপদ র‍্যান্ডম স্ট্রিং (ডিফল্ট প্রোভাইড করা হবে)। |
| **Database URL** | Database Phase 1 | `DATABASE_URL` | লোকাল ডেভেলপমেন্টে সরাসরি SQLite ফাইল (`file:./dev.db`), ডেপ্লয়মেন্টে Neon/Supabase থেকে নেওয়া হবে। |
| **Gemini API Key** | AI Engine Phase 1 | `GEMINI_API_KEY` | [Google AI Studio](https://aistudio.google.com/) থেকে ১০০% ফ্রিতে নেওয়া হবে (কোনো ক্রেডিট কার্ড লাগবে না)। যখন এই ফেজে কাজ শুরু হবে, তখন চেয়ে নেওয়া হবে। |
